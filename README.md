# المؤيد (Al-Moayed)

منصة رياضيات البكالوريا السورية — **حل بيدك ما حدا بفيدك**

## Stack

Next.js 14 · Tailwind CSS · Shadcn/UI · Supabase · iron-session

## Setup

```bash
npm install
cp .env.local.example .env.local   # add Supabase keys
npx supabase db push
npm run dev
```
