# Implementation Plan: TEACH-004 Import Instruction Template

**Branch**: `003-import-instruction-template` (recommended) | **Date**: 2026-07-14 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/003-import-instruction-template/spec.md`

**Feature ID (registry)**: `TEACH-004` — UI enhancement to bulk import on `/teacher/quizzes/[id]` (extends existing import parsers; no schema changes)

## Summary

Add a tabbed **import instruction template** above the existing file dropzone in `BulkQuestionUpload`: Excel/CSV column guide + downloadable sample `.xlsx`, Word/Text plain-block preview + `.docx` callout, and a persistent Arabic validation hint (`import-validation-tips`). Extend `parseWordLikeText` to accept `الشرح:` / `التصنيف:` aliases alongside legacy `شرح:` / `قسم:`.

**Technical approach**: Extract new client components under `src/components/teacher/import/`; add pure helpers in `src/lib/import-template.ts` for column metadata and client-side XLSX generation (reuse existing `xlsx` dependency); wire into `BulkQuestionUpload` before `FileUploadZone`; add Vitest coverage for parser aliases and template row shape.
