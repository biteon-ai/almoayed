# Implementation Plan: Teacher Student Management Hub

**Branch**: `006-student-management-hub` | **Date**: 2026-07-22 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/006-student-management-hub/spec.md`

**Feature IDs (registry)**: `TEACH-001` (evolve), `TEACH-002` (preserve/extend group clear), `TIER-002` (preserve Pro approve/revoke UX), `MT-002` (enforce), `ENABLE-001` (preserve Spekit hooks)

## Summary

Upgrade `/teacher/students` from a basic filtered list into a **Student Management Hub**: manual add (name + WhatsApp), real-time search, tier/status/group filters, unified card/row roster, 8-per-page pagination, inline status/Pro/group controls, edit (name + group; WhatsApp read-only), unlink with AlertDialog, and deactivate confirmation. All mutations stay in Server Actions scoped to the teacher’s `profileId`.

**Technical approach**: Extend `src/actions/teacher.ts` with create/update/unlink/group-clear helpers (reuse `updateStudentStatus` / `updateStudentTier`); refactor `StudentManagement.tsx` into a hub shell + dialogs; client-side filter + paginate over the teacher-scoped list already loaded by RSC; add a lightweight `Dialog` primitive mirroring existing `AlertDialog`; ephemeral success toast/live region (no new toast library).
